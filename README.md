# AI Personal Assistant

This is an AI Personal Assistant project built using Flask and OpenAI API.

The project provides a web interface where users can ask questions and summarize email content using an AI model.

## Technologies Used

- Python
- Flask
- OpenAI API
- HTML
- CSS
- JavaScript

## Features

- Ask questions and get AI-generated responses
- Summarize email content
- Web interface using HTML, CSS and JavaScript
- Flask backend for handling requests
- OpenAI API integration
